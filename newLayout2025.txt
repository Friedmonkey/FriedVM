  VLQ symbols address

varibles/types definitions:
while (pc < program start address)
	TypeByte, amount with default value, amount with embedded value, amount constant

program start address:
while (pc < const pool address)
{
	1 OPCODE
	for (OPCODE.argumentCount)
		VLQ index/address of varible
}
